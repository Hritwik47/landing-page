# Learnly – Landing Page

A modern landing page for an online learning platform, built as part of The Odin Project.

## Built With

- HTML5
- CSS3

## Features

- Hero section
- Navigation bar
- Course cards
- Learning statistics section
- Call-to-action section
- Footer

## Project

This project was created to practice HTML and CSS fundamentals, including:

- Semantic HTML
- CSS Flexbox
- Layout and spacing
- Typography
- Images
- Buttons and cards

## The Odin Project

This project is part of the Foundations course from The Odin Project.
